# Kaleido O.S — Static Demo

نسخة HTML/CSS/JS ثابتة مُصدّرة من آخر حالة محلية للنظام بتاريخ 2 سبتمبر 2026.

## التشغيل

افتح `index.html` مباشرة في المتصفح. النسخة لا تحتاج PHP أو Laravel أو قاعدة بيانات، وتعمل من GitHub Pages.

## المحتوى

- لوحة التحكم
- العملاء (CRM): مسار البيع، العملاء الحاليون، الأرشيف، وصفحات التفاصيل
- المشاريع والتاسكات وصفحات التفاصيل والإضافة والتعديل
- جدولة التصوير والمعدات والموارد
- الفريلانسرز والأقسام وتاسكات الأقسام
- تقارير الربحية والفواتير
- المستخدمون والأدوار والصلاحيات وبيانات الشركة

كل البيانات المعروضة بيانات تجريبية مأخوذة من بيئة التطوير. عمليات الحفظ والحذف ورفع الملفات معطلة لأنها تحتاج خادمًا وقاعدة بيانات.
