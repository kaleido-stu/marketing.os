# Kaleido O.S — ديمو العميل

نسخة مستقلة جديدة من شاشات Marketing OS الحالية، بتاريخ 9 نوفمبر 2026.

## التشغيل

افتح **index.html** مباشرة بالمتصفح. لا تحتاج تثبيت أو PHP أو Laravel أو قاعدة بيانات أو اتصال إنترنت. ويمكن البدء من **login.html** لعرض شاشة الترحيب والدخول التجريبي.

للمشاركة: أرسل ملف **client_demo.zip**، واطلب فك الضغط أولًا ثم فتح index.html. ويمكن رفع محتويات المجلد على استضافة ملفات ثابتة.

## سيناريو عرض مقترح

اضغط **جولة في النظام** أعلى أي شاشة، أو اتبع الترتيب التالي:

1. **لوحة التحكم**: مؤشرات الوكالة، الإيرادات، التصوير الجاري والمتابعات.
2. **العملاء CRM**: مسار البيع، البحث والفلاتر، ملفات العملاء، سجل التواصل، الأرشيف والتحويل.
3. **عروض السعر**: البنود والكميات والأسعار والطباعة؛ قبول عرض ينشئ مشروعًا وفاتورة تجريبيين.
4. **المشاريع والتاسكات**: بيانات الإدارة، نطاق العمل والمخرجات، المسؤول والفريق والأقسام، حالات التنفيذ والمراجعة، الخطوات والمرفقات وتوقيت العمل.
5. **جدولة التصوير والمعدات**: تقويم الشهر والأسبوع واليوم والموارد، تفاصيل الحجوزات، نماذج الحجز وكشف تعارض المعدات.
6. **الحسابات**: الفواتير وبنودها وطباعتها، تسجيل الدفعات، المصروفات وتقارير الربحية.
7. **الفريق والإعدادات**: الفريلانسرز والأقسام والمستخدمون والأدوار والصلاحيات وبيانات الشركة وسجل النشاط وواجهة أمان الحساب.

## التفاعل والحفظ

- التنقل والشاشات والنوافذ والقوائم والرسوم البيانية والتقويم تعمل محليًا.
- الإضافة والتعديل والحذف والأرشفة والملاحظات وتحديث حالات التاسكات وتسجيل الدفعات وقبول عروض السعر تحاكي العمل داخل المتصفح.
- التغييرات التجريبية تُحفظ في localStorage لهذا المتصفح. تظهر في لوحة **تغييرات العرض المحفوظة** داخل القسم، ومنها يمكن فتح التفاصيل المحدثة والسجلات الجديدة.
- الجداول والمجاميع والتقارير الأساسية لقطة ثابتة من النظام؛ لا يعاد احتساب جميع الشاشات والتقارير تلقائيًا بعد التعديلات المحلية.
- **إعادة ضبط** أعلى الشاشة تمسح تغييرات الديمو وتعيد البيانات الأولية.
- للطباعة استخدم شاشات طباعة الفاتورة وعرض السعر، ثم طباعة المتصفح أو الحفظ بصيغة PDF.

## حدود نسخة العرض

كل الأسماء والاتصالات والبيانات بيانات تجريبية مستقلة. لا تتصل النسخة بالنظام الحقيقي أو قاعدة بياناته.

الإرسال بالبريد وواتساب، تسجيل الدخول الفعلي، دعوات المستخدمين، تغيير كلمات المرور، التحقق بخطوتين، فرض الصلاحيات على خادم، وحفظ محتوى الملفات المرفوعة تتطلب النظام المتصل؛ الديمو يعرض واجهاتها أو يوضح أنها محاكاة، ولا ينفذها حقيقةً. رفع المرفقات يسجل الاسم محليًا فقط. النسخة المقدمة باللغة العربية.

## الملفات

- 139 صفحة HTML، تشمل صفحات التفاصيل والإضافة والتعديل والطباعة والدخول.
- assets/css وassets/modules: تنسيق النظام والأقسام.
- assets/js: JavaScript الأصلي للواجهة.
- assets/demo.js وassets/demo-data.js وassets/demo.css: تشغيل الديمو وبياناته وشريط العرض والجولة.
- assets/fonts وassets/vendor: خطوط ومكتبات محلية لتشغيل النسخة دون إنترنت.

لا توجد ملفات PHP أو قواعد بيانات أو ملفات إعدادات سرية داخل هذا المجلد.
