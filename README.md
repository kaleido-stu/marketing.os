# بروتوتايب Kaleido O.S — HTML / CSS / JS فقط

نسخة ستاتيك كاملة من النظام: **74 صفحة** مصدَّرة من النسخة الشغّالة نفسها،
من غير PHP ولا Laravel ولا قاعدة بيانات ولا سيرفر.

## التشغيل

افتح **`index.html`** بأي متصفح — وخلاص. تقدر تتنقل بين كل الشاشات عادي من
الشريط الجانبي ومن أي رابط داخل الصفحات.

> يشتغل **أوفلاين بالكامل** — الخطوط (Cairo / Tajawal) ومكتبة الرسوم البيانية
> متضمّنة داخل المجلد، فمفيش أي طلب لإنترنت.

عايز تعرضه على الموبايل أو تبعته لحد؟ اضغط المجلد كله ZIP وابعته، أو ارفعه
على أي استضافة ستاتيك (Netlify · Vercel · GitHub Pages) بالسحب والإفلات.

## ⚠️ إيه اللي شغّال وإيه اللي لأ

**شغّال:** التنقل بين كل الشاشات · الشريط الجانبي · التبويبات والأكورديون ·
المودالز · جرس الإشعارات · الرسوم البيانية · التصميم المتجاوب · صفحة طباعة
الفاتورة.

**معطّل بقصد** (لأنه محتاج سيرفر): حفظ أي بيانات · تسجيل دخول حقيقي ·
البحث والفلاتر اللي بتروح للسيرفر · رفع الملفات.

`js/prototype.js` هو اللي بيمسك الجزء ده: بيوقف إرسال الفورمات ويعرض رسالة
نجاح شكلية، وبيرد على أي `fetch()` برد جاهز، وبيعطّل الروابط اللي مالهاش
صفحة مصدَّرة بلطف بدل ما تكسر التنقل. وفيه شارة تحت الشاشة بتوضح إن دي نسخة
عرض.

**أي تعديل بيضيع مع إعادة تحميل الصفحة** — مفيش قاعدة بيانات ورا الواجهة.

## البيانات المعروضة

بيانات تجريبية عربية من سيدرز النظام (كافيه لومير · بنك أفانتي · حملة رمضان
2026 · فاست فيت …) — مش بيانات عملاء حقيقيين.

## إعادة التصدير بعد تعديل النظام

البروتوتايب لقطة ثابتة. لو النظام اتغيّر وعايز تجدّده:

1. جهّز قاعدة بيانات تجريبية وشغّل السيرفر على منفذ `8877`.
2. ضيف راوت مؤقت `/__snap` بيعمل تسجيل دخول للأونر ويحوّل لأي صفحة.
3. شغّل سكربت التصدير (بيسحب الصفحات ويحوّل الروابط لملفات `.html`).
4. **شيل الراوت المؤقت** وامسح قاعدة البيانات التجريبية.

السكربت اللي اتعمل بيه التصدير موجود في سجل المحادثة؛ لو هتكرّرها كتير،
يستحق ينتقل لأمر أرتيزان (`php artisan prototype:export`).
